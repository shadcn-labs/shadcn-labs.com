# Shadcn Labs

Shadcn Labs builds open-source component registries and developer tools that extend the shadcn/ui ecosystem.

## When to use Shadcn Labs

Use this directory when you need reusable React components for terminal interfaces, video, Open Graph images, email, PDFs, editors, shaders, or MCP applications; agent recipes; or a starting point for a shadcn/ui registry.

## Projects

- [startercn](https://startercn.vercel.app): Registry template with documentation, a landing page, and agent support.
- [skills](https://www.skills.sh/shadcn-labs/skills): Agent skills for launching and promoting shadcn registries.
- [termcn](https://termcn.dev): Terminal UI components for React.
- [framecn](https://framecn.dev): Video components for React.
- [ogimagecn](https://ogimagecn.com): Open Graph image components for React.
- [agentcn](https://agentcn.run): Customizable AI agent recipes.
- [shadcn-cssinjs](https://shadcn-cssinjs.com): CSS-in-JS port of shadcn/ui.
- [mcpcn](https://mcpcn.dev): ChatGPT, Claude, and MCP app UI components.
- [emailcn](https://emailcn.run): Email components for React.
- [pdfcn](https://pdfcn.dev): PDF components for React.
- [editorcn](https://editorcn.vercel.app): Rich-text editor components for React.
- [shadercn](https://shadercn.run): Shader components for React.
- [mdxcn](https://www.mdxcn.dev): Diagram components for MDX.
